Privacy Policy

This bot is a personal, single-user automated trading tool for Kalshi Perps (cryptocurrency perpetual futures). This page describes the data it accesses and how it's used, specifically in connection with its optional integration with the Meta Threads API.

What this integration does

When enabled, the bot posts a short, automated note to a single Threads account every time it enters a real trade -- the ticker, position side, entry price, take-profit/stop-loss targets, and the reason the trade was entered. It may also post a short note when the trading server restarts.

This is one-way, outbound posting only. The bot does not read, monitor, collect, or store posts, replies, likes, followers, or any other data belonging to the Threads account or to any other Threads user.

What data is accessed

  • An OAuth access token authorizing this app to publish posts as the single account that completed the login (Threads API scopes: threads_basic, threads_content_publish).
  • The Threads user ID needed to address that account's own post-publishing endpoint.

No data about any other person or account is accessed, collected, or processed.

How data is stored

The access token is stored privately (mirrored to a private Hugging Face model repository the operator controls, so the bot doesn't need a fresh login after every server restart). It is never shared with, sold to, or made accessible to any third party. It is used solely to authenticate the automated posts described above.

Data deletion

The account owner can revoke this app's access at any time from their Meta/Threads account settings, which immediately invalidates the stored token. The operator can also delete the stored token directly.
